# Referência visual e institucional — Grupo Arqueo

A expansão 0.4 usa o Grupo Arqueo apenas como identidade visual do ambiente, sem transformar o Coletor IPHAN em outro produto.

Referências consultadas em 15/10/2026:

- [Site oficial](https://grupoarqueo.com.br/): posicionamento como hub de soluções integradas para Patrimônio Cultural, Arqueologia, Educação, Tecnologia, Gestão e Comunicação.
- [Quem Somos](https://grupoarqueo.com.br/quem-somos/): missão, visão, valores e unidades independentes.
- [Espaço Ética](https://grupoarqueo.com.br/espaco-etica/): ética, transparência e integridade como linguagem institucional.

## Aplicação no Coletor

- O logo oficial selecionado foi incorporado como `group-arqueo-logo.png` e servido localmente; não há dependência de carregamento externo.
- Paleta de apoio: azul-marinho para navegação e contraste, laranja para ação, vinho para marca e azul para acentos informativos.
- A linguagem da interface continua técnica e rastreável, coerente com a responsabilidade documental do Coletor.
- A marca não altera o escopo funcional: não cria módulos financeiros, contábeis ou comerciais.
