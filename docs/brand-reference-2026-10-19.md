# Referência visual — Coletor IPHAN e Grupo Arqueo

A interface do Coletor IPHAN usa a marca local do Grupo Arqueo já incluída no projeto. A referência institucional foi adotada somente para orientar a apresentação visual do repositório técnico, mantendo o produto focado em patrimônio cultural, arqueologia, processos, documentos e evidências.

O site oficial do Grupo Arqueo apresenta a organização como um hub de soluções para Patrimônio Cultural, Arqueologia, Educação, Tecnologia, Gestão e Comunicação. A página institucional também destaca confiança, transparência, integração e responsabilidade. No Coletor, esses princípios aparecem como proveniência do documento, estados explícitos da fila, evidência antes de conclusão e indicação clara de recursos que não foram homologados.

A paleta aplicada na interface preserva azul-marinho para contexto institucional, azul de apoio para informação, vinho para avisos e laranja para ações. A logo do Grupo Arqueo permanece como marca principal do aplicativo. Não existe neste escopo cadastro de empresas, logo por empresa, relatórios financeiros, fluxo de caixa, DRE ou EBITDA.
